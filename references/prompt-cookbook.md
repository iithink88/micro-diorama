# 微缩景观提示词范例集

写新提示词前先读本文件找语感。所有范例共用六段公式与五个硬锚点，差异只体现在"主体细节"和"环境层次"两段。

## 一、原作范例（爱云画AI《如果把中国的著名景点，缩小成一个精致的微观世界》）

这四段是这条提示词路数的原型，结构高度一致，值得逐句拆解。

### 拆解：为什么这四段有效

| 手法 | 原文证据 | 作用 |
|---|---|---|
| 开篇即定性"模型" | "制作成精致的微缩立体模型" | 第一句就锁死尺度，防止模型跑成实景 |
| 给世界一个名字 | "紫禁城微型世界""江南庭院世界" | 让画面有完整感与边界感，而不是建筑孤立摆放 |
| 数字化的视角 | "45度俯视" | 最保险的沙盘视角，既有立体感又不失平面布局可读性 |
| 唯一视觉中心 | 太和殿／黄鹤楼／水池 | 避免细节平均用力导致画面失焦 |
| 材质三连 | 金黄琉璃瓦、朱红宫墙、汉白玉台基 | 颜色＋材质成对出现，比单写"红墙黄瓦"信息量高 |
| 地形切面 | "底部呈现自然的地形切面" | 一句造出"被切开的一块地"的模型感，最关键的一句 |
| 悬浮设定 | "悬浮于纯净背景中的微缩建筑岛屿" | 背景干净，主体自带体积 |
| 意象化收尾 | "壮观但精巧""梦幻而不失真实" | 用形容词对子给情绪定调，模型语言不落俗 |
| 双写锚点 | 中文叙述 + 英文 diorama/isometric/photorealistic | 兼容中外模型，风格稳定 |

## 三、变量替换速查

同一主体换风格时，只改末段的渲染词与配色，结构保持不动：

| 想要的版本 | 末段替换写法 |
|---|---|
| 黏土手工感 | claymation style, handmade clay texture, soft studio light, 指纹与刀痕痕迹, 马卡龙配色 |
| 纸艺拼贴 | papercraft diorama, layered paper cut, visible paper grain, soft shadow, 莫兰迪配色 |
| 木质模型 | wooden architectural model, basswood and balsa, laser-cut edges, workshop light |
| 水彩绘本 | watercolor illustration, soft edge bleeding, grainy paper, muted palette |
| 赛博朋克 | cyberpunk neon, holographic signage glow, wet reflective surfaces, teal and magenta |
| 冬季限定 | 覆盖薄雪，屋顶与树梢积雪，暖黄窗光，冷蓝环境色，呼气白雾 |
| 夜景限定 | 夜间，建筑内部透出暖光，路灯形成光斑，天空深蓝带星，地面湿润反光 |
| 四季系列 | 春樱/夏荫/秋枫/冬雪 分别替换植被与配色描述，其余不动 |
